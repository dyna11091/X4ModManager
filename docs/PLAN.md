# X4 mod管理器开发计划

## 产品边界

目标是管理“已经安装在本机”的 X4 扩展，不建设在线 MOD 商店或搜索引擎。首要原则是轻量、透明、可恢复：应用只读取 MOD 文件，并只在用户点击“应用更改”后修改玩家配置 `content.xml`。

## 里程碑

### M1：可用的本地管理器（当前）

- 自动/手动定位游戏与玩家配置。
- 读取游戏版本、MOD 元数据和当前启用状态。
- 扫描游戏目录、玩家目录和 Steam Workshop。
- 一键启停、批量启停、备份、原子写入和写后校验。
- 打开来源页、文件夹及浏览器快捷翻译。
- 来源筛选、功能分类、多选拖动、别名、可持久化排序和白天/夜间主题。
- 从管理器启动游戏，并允许启停官方 DLC。

验收：核心测试通过，Release 构建成功，并可在没有网络连接时完成扫描和启停。

### M2：来源识别与内嵌翻译

- 读取更多 Nexus/Vortex 元数据格式，并允许为无法识别来源的 MOD 保存自定义页面。
- 提供可选的内嵌翻译服务；密钥仅保存在本机，未配置时继续使用浏览器翻译。
- 显示缺失依赖、重复扩展 ID 和来源重复安装警告。

### M3：配置集与存档保护

- 保存、载入多套 MOD 配置。
- 对照存档中记录的扩展列表，加载前提示缺少或禁用的依赖。
- 提供配置导入/导出，不打包或再分发第三方 MOD。

### M4：发布（已完成）

- 生成单文件、自包含的 Windows x64 包。
- 增加图标、版本信息和更新说明。
- 在真实 Steam、GOG 目录结构上做回归验证。

## 明确不做

- 在线搜索或浏览 MOD 库。
- 绕过 Steam/Nexus 的访问控制或下载限制。
- 未经确认删除 MOD、存档或游戏文件。
- 自动修改 MOD 内容以“修复”冲突。
